# 可研项目查重

用于判断拟建项目与历史项目是否存在需求、建设内容或功能能力上的实质重合，为识别重复建设提供原文证据和查重报告。

输入为单份可研文档或包含多份可研文档的文件夹。查重工作流负责：

1. 从可研中提取项目需求、项目目标、预期成果、建设内容和功能清单。
2. 在历史项目知识库中检索相关项目片段。
3. 对照新项目条目和历史原文，评估业务及功能重合程度，给出相似度和引用证据。
4. 按工作流中的判定规则生成查重结论和报告。

查重针对项目业务及建设内容，不是通用的文字重复率检测。报告中的具体字段与判定规则以服务端已发布工作流的实际输出为准。

## 使用方式

通过随包脚本将文档提交给已配置的查重工作流，并将返回的报告保存为 Markdown。信息提取、知识库检索、证据评估和重复判定均由工作流完成。不要在本地另跑 project-dedup 的检索和评分步骤，也不要改写工作流返回的证据、相似度或结论。

本技能可整体复制，脚本仅依赖 Python 标准库。下文 SKILL 指本文件所在目录。

## 输入与输出

- 用户输入：一份可研文档的路径，或存放多份可研文档的目录；可指定报告输出目录。
- 工作流输入：将当前文档上传后，把文件引用放入开始节点的实际文件变量。变量名由配置中的 `input_name` 指定，留空时从接口自动识别唯一文件变量，不固定为 `file` 或其他名称。单文件变量传文件对象，文件列表变量传仅含当前文档的数组。其他输入通过 `--inputs-json` 提供，不自行编造工作流变量。
- 工作流输出：读取执行完成事件中的 `data.outputs`。本技能不定义新的查重报告格式，也不替工作流补充评估结果。
- 本地输出：每份源文档生成一个同名 `.md` 报告，目录批量处理保留相对目录结构。当前脚本优先取输出字段 `result`、`answer`、`output`、`text`、`report`、`markdown`、`error_msg` 中第一个非空值；若均未匹配，只有一个输出字段时取其值，多个字段时保存为 JSON 文本。非字符串值同样保存为 JSON 文本。若报告字段未被正确选中，应先适配实际结束节点输出，不将整个响应自行解释为查重结论。
- 失败结果：执行失败或无报告时记录“查重未完成”和错误原因，退出码非零；部分转换或准备失败可能只记录在终端日志，需一并检查。

## 配置与检查

连接信息统一读取 `config/workflow.json`，不在本文件维护服务地址或应用标识。按配置中 `api_key_env` 指定的环境变量读取应用密钥，不打印密钥。调用已发布的工作流。

```powershell
python SKILL/scripts/run.py --check
```

检查会读取 `/v1/parameters`，不上传或执行文档。脚本要求明确或唯一可识别的 file / file-list 输入。多个文件变量时，在配置中填写 `input_name`，或传 `--input-name`。其他必填输入通过 `--inputs-json` 提供一个 JSON 对象文件。缺少密钥或输入配置时，说明具体缺项，不要猜测或转用未鉴权的 Web 接口。

## 执行

```powershell
python SKILL/scripts/run.py --input "C:/资料/可研报告.docx" --output "C:/资料/查重结果"
python SKILL/scripts/run.py --input "C:/资料/待查重" --output "C:/资料/查重结果"
```

支持 docx、doc、wps 等 Word 文档；目录递归扫描，每份文档单独运行一次工作流。非 docx 文档先调用本机 WPS/Word、LibreOffice 或 macOS textutil 转换为临时 docx。缺少转换工具时保留错误并说明原因。文件列表变量每次传入仅含当前文档的列表。

服务地址可用 `--api-base` 覆盖，支持带或不带 `/v1`。用 `--limit 1` 小批验证；`--timeout` 是网络等待超时，不保证服务端停止执行。执行使用 SSE 流式返回。断流或超时后不要自动重新提交同一文件，因为原任务可能仍在服务端运行，应先检查 Dify 运行日志。

已有报告会被覆盖，重复处理前检查用户是否希望重跑，或使用新的输出目录。原始文档不改动。输出目录每个源文件对应一个 Markdown 报告；失败写“查重未完成”，不得将失败当成“不重复”。批量退出码非零时检查逐篇结果。

## 汇报

读取生成的报告，向用户说明查重结论、涉及的相似历史项目、主要重合点及对应证据，并提供报告路径。批量处理时汇总成功和失败数量，分别说明各项目结论。只引用报告实际提供的信息；无法明确识别结论时如实说明，保留报告原文。
